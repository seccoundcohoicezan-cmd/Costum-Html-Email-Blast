🔖 Placeholder yang Digunakan

Placeholder berikut ada di dalam HTML template. Mule akan mengisi nilai ini dari kolom spreadsheet:

🟢 Data dari spreadsheet  |  🔵 Data dari Konfigurasi (sudah terisi)  |  🟣 Opsional  |  🟠 Custom Placeholder (kolom kustom Anda)

📋 Format Placeholder di HTML Email Wajib Baca
Agar placeholder terbaca oleh sistem blast, nama kolom di spreadsheet HARUS sama persis dengan placeholder di bawah (huruf besar, spasi diganti underscore).

Kolom Spreadsheet 📊 FormMule (di HTML) 🐒 Listmonk (di HTML) Contoh Nilai
NAMA <<NAMA>> {{ .Subscriber.Name }} Vania Dido Azzahra
EMAIL <<EMAIL>> {{ .Subscriber.Email }} vania@email.com
LINK SERTIFIKAT PELATIHAN <<LINK_SERTIFIKAT_PELATIHAN>> {{ .Subscriber.Attribs.link_sertifikat_pelatihan }} https://drive.google.com/...
LINK SERTIFIKAT BEASISWA <<LINK_SERTIFIKAT_BEASISWA>> {{ .Subscriber.Attribs.link_sertifikat_beasiswa }} https://drive.google.com/...

Legenda: <<X>> = dari kolom spreadsheet {{x}} = dari Konfigurasi (fixed) {{ .Subscriber }} = Listmonk Go Template <<X>> = opsional

⚠️ Aturan Agar Placeholder Terbaca

📊 FORMMULE
✅ Header kolom = NAMA, EMAIL, dst
✅ Placeholder di HTML: <<NAMA>>
✅ Spasi di nama kolom → _ (underscore) di placeholder
✅ HTML body = 1 baris (sudah otomatis)
❌ Jangan pakai karakter: " , < > di nilai sel
❌ Nilai dengan koma → bungkus dengan "kutip ganda"
🐒 LISTMONK
✅ Nama = {{ .Subscriber.Name }}
✅ Email = {{ .Subscriber.Email }}
✅ Kolom custom = {{ .Subscriber.Attribs.key }}
✅ Key di Attribs = huruf kecil + underscore
✅ Template type = Campaign / HTML
✅ Sudah ada {{ template "content" . }} otomatis

2. Nilai dengan koma dibungkus tanda kutip ganda
3. Ukuran ideal per cell: < 32.767 karakter
